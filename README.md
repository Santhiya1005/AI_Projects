Netflix Customer Churn Prediction 🎬

This is a Machine Learning web app that predicts whether a Netflix customer will cancel their subscription (churn) based on customer details.

About the Project

Customer churn is a major problem for subscription platforms.
This project predicts churn in advance so businesses can take action to retain customers.

# How it Works

User enters customer details →
Data is preprocessed →
ML model predicts churn →
Result is shown in Streamlit app.

# Input Features

Age

Tenure

Monthly Charges

Satisfaction Score

City

Python

# How to Run the Project

Clone the repository

git clone <your-repo-link>


Install dependencies

pip install -r requirements.txt


Run the app

streamlit run app.py
